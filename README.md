# Zombie English

Браузерная обучающая игра по английскому языку в сеттинге комиксного зомби-апокалипсиса.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run typecheck
npm test
npm run build
```

В игре доступны три района и три учебные миссии: Past Simple, Pronouns и Clothes. Прогресс сохраняется локально в браузере.
